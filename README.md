# Paradise Nursery Shopping Application

A React-based online plant shop with a shopping cart using Redux Toolkit. Users can browse plants, add to cart, update quantity, and remove items.

## Features

- Browse plants by categories
- Add to cart and disable added items
- Update quantity and remove items in cart
- Show subtotal per item and total cart amount
- Continue shopping button
- Checkout button (Coming Soon)

## Technologies

- React, Redux Toolkit, React-Redux
- Vite
- GitHub Pages (for deployment)

## How to Run
npm install
npm run dev
and open in your localhost
